# GOKUL GHEE Backend (MVC Scaffold)

This directory holds the modular MVC backend structure for Phase 3–6:
- `config/` — MongoDB Atlas, Cloudinary, Razorpay, Gemini, CORS
- `models/` — User, Product, Category, Order, Inventory, Address, Coupon, Review, Conversation, AIUsage, DeliveryZone, Notification, AnalyticsEvent
- `controllers/` — Request handlers
- `routes/` — Versioned REST routes
- `middleware/` — Auth, RBAC, validation, rate limiting, error handling
- `services/` — Order transactions, stock reservation, Gemini grounding, pincode serviceability
- `validators/` — Zod validation schemas
- `utils/` — Error helpers & formatters
